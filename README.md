## RecipeGenerator

# Vosk API

Utilized this to help with voice recognition. The purpose of this feature is to help users speak out their ingredients and the Vosk API converts that to text.

# Tasty API

This API helped with finding recipes for the given ingredients and displaying recipe videos for the respective recipes.

# Purpose

The purpose of this app is to help users have a healthier alternative. Many people eat out a lot and it hurts them financially and physically. There is a high obesity rate in America and we aim to help reduce that by giving users simple recipes that can be easily made at home.
